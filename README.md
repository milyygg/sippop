# SIPPOP! Drink your mood.

Законченный интерактивный концепт молодёжного бренда напитков. React + TypeScript + Vite + Tailwind CSS + Motion + Zustand + Lucide. Статическое SPA без сервера и платежей.

## Запуск на компьютере

Нужен Node.js 22.12+ или 24 LTS. Откройте терминал в папке проекта:

```powershell
cd 'B:\Neyro\ChatGPT_Codex\Project\12_Кофейня'
npm install
npm run dev
```

Откройте адрес, показанный в терминале, обычно http://127.0.0.1:5173. Для остановки нажмите Ctrl+C. Файл index.html не нужно открывать двойным щелчком: Vite обрабатывает TypeScript и импорты.

## Сборка и проверки

```powershell
npm run typecheck
npm run lint
npm test
npm run build
npm run preview
```

Готовая сборка находится в `dist`. `npm run preview` показывает именно сборку, обычно на порту 4173.

Браузерные сценарии:

```powershell
npm run test:e2e
```

По умолчанию тесты используют Microsoft Edge, установленный в стандартном каталоге Windows. Для другой ОС или браузера измените executablePath в playwright.config.ts или уберите его и установите браузер Playwright командой `npx playwright install chromium`. В scripts/visual-qa.mjs путь также задан для текущего Windows-компьютера.

## Что реализовано

- Пять настроений Hero, синхронная смена кадра, текста, фона и акцентов; стрелки клавиатуры в группе переключателей.
- Параллакс только для мыши, floating, reveal, 3D tilt, анимированные переходы. Можно отключить движение в подвале. Системный reduced-motion учитывается.
- Flavor Universe, каталог из 24 товаров в 6 категориях, три Signature Drinks, история бренда, промоблок, примеры отзывов, будущая локация, подвал.
- Объёмы с разными ценами, добавление, удаление, количество, итог, очистка и сохранение корзины в localStorage.
- Демооформление: самовывоз/доставка и честное финальное сообщение.
- RU/EN, светлая/тёмная тема, сохранение настроек, системная тема при первом посещении.
- Нативный модальный dialog для корзины: Escape, блокировка фона, удержание и возврат фокуса.
- Локальные WebP-изображения, локальные WOFF2-шрифты, lazy loading, отдельный JS chunk корзины, SVG favicon, Open Graph.

GSAP и WebGL не добавлены: необходимую анимацию обеспечивают Motion и CSS без второй конкурирующей системы.

## Как загрузить на GitHub

1. Создайте аккаунт GitHub, если его ещё нет.
2. Установите GitHub Desktop с официального сайта https://desktop.github.com/.
3. Выберите File > Add local repository и папку проекта. Если репозиторий ещё не создан, используйте предлагаемое Create a repository here в этой папке.
4. Проверьте список файлов: node_modules и dist должны быть исключены через .gitignore. Исходники, public и package-lock.json нужны в репозитории.
5. Напишите описание первого коммита, например `Create SIPPOP concept`, нажмите Commit, затем Publish repository. Приватность выбираете вы.

Альтернатива для тех, кто использует Git: `git init`, `git add .`, `git commit -m "Create SIPPOP concept"`, затем подключите созданный на GitHub репозиторий как origin и выполните push по инструкции GitHub. В этой работе push не выполнялся.

## Как опубликовать через Vercel

1. Войдите на https://vercel.com через GitHub.
2. Выберите Add New > Project и импортируйте репозиторий SIPPOP.
3. Framework Preset: Vite. Root Directory: корень проекта. Install Command: `npm install` (либо `npm ci`). Build Command: `npm run build`. Output Directory: `dist`.
4. Переменные окружения для этого проекта не требуются. Нажмите Deploy.
5. После публикации Vercel покажет настоящий адрес. Если подключите свой домен, обновите SEO в index.html: добавьте canonical и og:url, а og:image сделайте абсолютным URL настоящего домена. До этого случайный домен в код не записан.

Клиентских маршрутов здесь нет: навигация якорная, rewrites не нужны. Vercel автоматически распознаёт Vite. Создание репозитория, вход в аккаунты и публикация остаются за владельцем.

Официальные инструкции: [Vite на Vercel](https://vercel.com/docs/frameworks/frontend/vite) и [добавление локального репозитория в GitHub Desktop](https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-a-repository-from-your-local-computer-to-github-desktop).

## Демонстрационные ограничения

SIPPOP! - вымышленный бренд для портфолио. Все товары, цены, составы и отзывы являются демонстрационными. Изображения напитков и десертов созданы ИИ, а не сняты у настоящего бизнеса. Для некоторых позиций используются общие визуализации соответствующего вкуса, они не документируют точный состав или температуру подачи каждого рецепта. Классический кофе показан общим кофейным визуалом.

Заказы не отправляются, оплата не принимается, контакты и адрес не собираются. Корзина сохраняется локально на устройстве и не очищается при завершении демооформления, чтобы пример можно было повторить. Первая точка не имеет объявленного адреса; схема декоративная.

Lighthouse 90+ не заявляется: отдельный Lighthouse-замер не проводился. Автоматические проверки и их ограничения записаны в QA.md.

## Архитектура и воспроизводимость

`src/components`, `src/sections`, `src/data`, `src/hooks`, `src/store`, `src/i18n`, `src/styles`, `src/assets`, `src/lib` разделяют UI, контент и логику. Зависимости зафиксированы в package-lock.json. Для воспроизводимой установки используйте `npm ci`.

Промпт и художественные решения: DESIGN.md и ASSETS.md. Генерация выполнена встроенным image_gen; scripts/prepare-assets.mjs выполняет только разрезание исходного листа, подрезку прозрачных полей и WebP-оптимизацию. scripts/fonts.mjs повторно скачивает шрифты из Google Fonts. scripts/visual-qa.mjs сохраняет снимки локального сайта.
