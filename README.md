## Запуск у себя

На телефоне напиток на первом экране плавно покачивается и реагирует на наклон устройства. Если браузер требует разрешение, нажмите «Включить наклон телефона». Без доступа к датчикам можно управлять движением касанием. Эффект учитывает системную настройку уменьшения движения и приостанавливается вне первого экрана. [Документация API датчиков](https://developer.mozilla.org/en-US/docs/Web/API/Device_orientation_events/Detecting_device_orientation).

Нужен Node.js 24. Скачайте репозиторий через **Code > Download ZIP**, распакуйте и выполните в папке проекта:

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Для сборки: `npm run build`. Готовая сборка публикуется в GitHub Pages из ветки `gh-pages`.

Технологии: React, TypeScript, Vite, Tailwind CSS, Motion, Zustand.
