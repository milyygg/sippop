# Проверка SIPPOP!

Дата: 2026-10-21. Windows, Node.js 24, браузер Microsoft Edge в headless-режиме через Playwright.

Итог: TypeScript, ESLint, production-сборка и 5 unit-тестов успешно пройдены. Два браузерных сценария пройдены и на dev-сервере, и на готовой production-сборке через npm run preview. npm audit сообщает 0 известных уязвимостей. HTTP-проверка главной страницы, локального изображения и локального шрифта production-сборки вернула 200.

## Автоматические проверки

- TypeScript: npm run typecheck.
- ESLint: npm run lint.
- Production: npm run build, выходная папка dist.
- Vitest: npm test, пять проверок состояния корзины и полноты данных.
- Playwright: npm run test:e2e, два комплексных сценария.
- npm audit: проверка известных уязвимостей установленного дерева зависимостей.

Браузерные сценарии проверяют 24 товара, категории, Hero, увеличение объёма и цены, добавление и изменение количества, сумму корзины, доставку, демонстрационное завершение, Escape и возврат фокуса, язык и тему после перезагрузки, сохранение корзины, мобильную навигацию, загрузку всех изображений и отсутствие runtime errors в основном сценарии.

Для проверки готовой сборки запустите npm run preview, затем в другом PowerShell: `$env:E2E_BASE_URL='http://127.0.0.1:4173'; npm run test:e2e`.

Проверяемые ширины: 320, 375, 390, 430, 768, 1024, 1440, 1920 px. На каждой измеряется отсутствие горизонтального overflow документа. Визуальные снимки светлого и тёмного первых экранов и полных страниц сохранены в qa/.

## Визуальная оценка

ROUND 1

Seen in one second: крупный клубничный стакан рядом с двухстрочным названием настроения.

Idea: POP из SIPPOP превращается в круговой мотив и интерактивный выбор цвета/вкуса.

Live thing: пять переключаемых настроений с синхронной сменой продукта и атмосферы.

Layout words by section: hero=product split / flavors=horizontal specimens / menu=filtered grid / signature=oversized panels / story=brand poster / promo=product campaign / reviews=quotes / locations=decorative map / footer=oversized wordmark.

Top three problems and fixes:
1. mobile-fold: переключатели попадали на нижний край первого экрана. Высота сцены привязана к svh.
2. desktop-fold: слова заголовка визуально сливались при плотном трекинге. Добавлен явный word spacing.
3. Внешний Google Fonts усложнял загрузку. Шрифты перенесены локально в WOFF2.

Оценки намеренно не выдаются за независимое жюри. Это внутренняя визуальная проверка, а не сертификат качества.

## Ограничения проверок

Инспектор taste-skill не смог запустить свой CDP-сеанс: Chrome exited early, code 0, в том числе при явном пути к Edge. Вместо него использованы работающие Playwright-сценарии, измерения и реальные скриншоты Edge. Не заявляется, что taste-skill inspector пройден.

Стилевой taste-skill lint фиксирует некоторые тени, тонкие линии и декоративные символы. Его предпочтения не являются ESLint-ошибками. Прямые требования ТЗ к объёмной презентации, цветовым темам и декоративным элементам имеют приоритет; исключения отражены в DESIGN.md. Модальные тени нужны для выделения реального overlay.

Длинный фиксированный слоган промоблока сохранён по ТЗ и может занимать больше двух строк. Автоматический подсчёт строк в qa/heading-layout.json является вспомогательным измерением, не оценкой доступности.

Lighthouse, реальные мобильные устройства, Safari и Firefox отдельно не проверялись. Полноценный аудит WCAG и ручной скринридер-тест не проводились. Фактический мобильный Lighthouse 90+ не заявляется.

## Ручная проверка

1. Откройте сайт на телефоне и компьютере. Переключите все пять вкусов и убедитесь, что кадр, заголовок, описание и цвет меняются вместе.
2. Переключите все категории. Добавьте один товар в двух объёмах, измените количество, удалите строку, очистите корзину.
3. Выберите самовывоз и доставку, завершите демозаказ. Должно появиться предупреждение о демонстрационной версии без полей личных данных и без оплаты.
4. Переключите язык и тему, обновите страницу. Настройки и корзина должны сохраниться.
5. Пройдите Tab по кнопкам и откройте корзину, нажмите Escape. Фокус должен вернуться к кнопке корзины.
6. Включите системное уменьшение движения или выключите анимации в подвале. Все функции должны работать.
